# COMPILED

Next.js App Router · TypeScript · Tailwind CSS 기반 해커톤 기본 페이지입니다.

## 실행

Node.js 20.9 이상과 Bun을 사용합니다.

```sh
bun install --frozen-lockfile
bun run dev
```

[로컬 페이지](http://localhost:3000)를 엽니다.

## 검증 및 프로덕션 실행

```sh
bun run lint
bun run typecheck
bun run build
bun run start
```

현재 화면은 반응형 헤더와 GitHub 링크로 구성되어 있습니다.
